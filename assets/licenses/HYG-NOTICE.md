The adapted star data, metadata and binary/base64 representation retain CC BY-SA 4.0. This asset license is separate from the application code license. Source data is provided as-is without warranties.

HYG's 4.1 README says some component names ending in B are unofficial. The application preserves this source caveat; they are not claimed to be newly approved IAU names.
