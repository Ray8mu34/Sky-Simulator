# NASA Earth images

Day map and independent cloud layer: NASA Goddard Space Flight Center / NASA Earth Observatory, Blue Marble 2002. Image by Reto Stöckli (land surface, shallow water, clouds); enhancements by Robert Simmon (ocean color and compositing). Supporting data: MODIS Land/Science/Atmosphere/Ocean teams; USGS EROS topography; USGS Antarctic data; NOAA observations. Source: https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/

Night layer: NASA Earth Observatory image by Robert Simmon, using Suomi NPP VIIRS data courtesy Chris Elvidge, NOAA National Geophysical Data Center. Night Lights 2012 Map, published 2012-11-27, assembled from April and October 2012 observations. Source: https://science.nasa.gov/earth/earth-observatory/night-lights-2012-map-79765/

These are static historical composites. Day imagery is mainly from June–September 2001. The 2002 cloud layer is a visible/thermal multi-day composite, not current weather. The night composite may contain fires and gas flares as well as cities, and is not a current population map.

Changes: WebP encoding and downsampling while preserving the geographic projection; the night map's blue basemap is suppressed to produce a display emission layer. Cloud brightness is used as an illustrative opacity mask. These processed textures are display approximations, not new NASA scientific products or quantitative radiance data.
