# 固定验收输入

本目录只提交永久测试所需的固定输入：科学参考原始响应、来源元数据和用于逐字节对比的旧算法夹具。保留原路径是为了不改变已锁定来源与相对导入；它们不是当前实现的第二套运行内核。

运行测试产生的JSON、截图、录屏、trace及构建快照默认被Git忽略。开发期间的历史输出已压缩保留在开发机 `_local-archive/2026-10-05-pre-publication/`，不随源码发布。

某些可选的历史浏览器诊断依赖旧候选包或报告，需要从本地归档恢复，或使用脚本提供的环境参数指定新夹具；它们不是普通构建的必需步骤。完整数据溯源检查还需要 `scripts/data_restore.py` 恢复 `assets/source/` 中哈希锁定的上游原件。仅恢复原资产并不自动重建HKO差异报告；可用原本地报告或按数据生成流程重算。

参考数据的提供者保留各自许可和免责声明；应用自有代码MIT不覆盖所有第三方资料。SOFA许可见 `tests/fixtures/m5b/SOFA-LICENSE.txt`，其他资料见 `assets/licenses/`。来源和生成元数据与相应夹具一同保存。
