# 设备时间地点与日期选择 · 2026-10-28

普通打开网站时读取设备当前日期、时刻和时区，并向浏览器请求单次定位。初始停在当前时刻；点“实时”以1倍速跟随时间。观测地点下的“此刻与当前位置”可重新同步。分享链接和主动载入的教学/保存场景优先使用场景自身数据。

日期改用原生日历，时刻改用原生时间选择器，支持秒和键盘编辑。选择结果先保留为草稿，点击“应用时间”后才切换天空并暂停。浏览器/操作系统拥有弹层样式与语言；Chrome、Edge的中文弹层已实际打开并验证。原有天文纪年入口移至“时区 / 纪年”，继续支持公元前与0年，固定教学预设数据不变。

## 定位与恢复

- 位置来自浏览器Geolocation，首次使用需浏览器授权；不以IP推断位置，不调用反向地理编码，不持续追踪设备。
- 拒绝、超时或不支持时保留原地点，提示重试或手动选择；设备时间仍可独立使用。
- 未取得有效海拔时明确按0 m计算；精度显示设备报告值。
- 手动编辑、导入或切换场景后，迟到定位不能覆盖新状态；错误后可重试，卸载后忽略回调。
- 时间采用设备时区，坐标不用于猜测时区。IANA民用输入仍限定1900–2100，其他年代使用固定UTC偏移；重复与缺失民用时刻继续由现有core校验。
- 位置不自动保存到服务端。用户主动保存、分享或导出场景时，场景按既有格式包含经纬度。
