# 科学模型与教学边界

本版以一致的时间、地点和科学快照驱动画面与读数。下面说明模型的含义，不把功能检查或有限参考样本解释为全时空精度认证。

## 时间与坐标

天文计算使用固定 Astronomy Engine 2.1.19。UT 数值以 2000-01-01 12:00:00 UTC 为起点；当前近似 UT1≈UTC，TT 使用引擎的 Espenak–Meeus ΔT 模型，未接入实时地球定向参数。

采用前推格里高利历和天文纪年：年 0 是公元前 1 年。输入范围为 −2000 至 +4000；古代 UTC 是数值显示约定，长期 ΔT、岁差和运动近似的限制不能由现代参考检查消除。IANA 民用时间使用主机时区规则，仅支持 1900–2100；地点和显示时区相互独立。

恒星基准为 J2000 赤道方向，图形统一变换到当日参考系与观测地点的地平系。赤道、黄道、天极和地平是不同的参考；天球半径与地球展示尺寸是教学比例，不表示星体距离。

## 恒星与日月

运行星表来自固定 HYG 4.1。来源身份、距离、径向速度和可用性字段符合本版政策时使用线性空间运动；缺失、零径向速度含义不明或字段异常时，保守回退到切面角自行，并在对象读数中说明。未知数据不会被当作已测量的零值。模型未加入恒星年度/站心视差、年度光行差、双星轨道或加速度。

日月计算来自引擎的站心与地心方向：当地地表和二维总览使用观测地点的站心口径，外部三视图的日月图形使用地心口径。详情中的高度是观测地点读数。“几何高度”在这里表示不施加大气折射，不表示移除光行时和光行差。

月相照亮比例、月面姿态和相邻四月相时刻使用科学计算。月相放大镜明确教学放大，并显示观察口径；地平下的月球仍可用于教学，但会提示当前不可见。本版没有真实月面地形阴影。新增日月食事件搜索与独立盘面几何模拟，主天空的大气亮度和月面尚未接入食象；模型与验证边界见[日月食增量说明](EXPLORATION-TOOLS.md)。

## 折射与升落

### 行星与深空目录增量

水、金、火、木、土五颗行星使用同一 Astronomy Engine 科学快照。地表图形与详情采用站心方向，外部三视图采用地心方向。行星的星点大小用于辨认，不是圆面角直径；详情列出计算角直径与照亮比例。行星复用定性星点亮度衰减，不新增测光标定。行星升落采用站心中心、34′海拔密度缩放标准折射，与引擎的行星点目标约定一致。

Messier 110个目标使用OpenNGC的J2000目录中心，通过同一观测参考系进行显示和折射变换；不推进深空天体自行。V波段总星等、长轴/短轴角尺寸保留源数据的空值，不用B波段替代V波段。尺寸来自混合目录口径，不作为统一等亮度边界。M40是双星、M73是星群；M102采用常见但存在历史争议的NGC 5866对应。

深空符号仅标示目录中心，固定屏幕尺寸不代表实际角尺寸。完整星图显示目录符号，应用当地可见性衰减时只显示选中深空目标；不从总星等推导延展天体肉眼可见性。M1、M31、M42的图像放在详情中，具有独立署名和波段说明，不作为天球贴图。深空升落查询未纳入本批功能。

画面折射可选几何或标准近似，按气压和温度修正视方向；压力 0 退化为几何方向。点、线、日月盘、银河、标签和拾取共用地表显示改正，外部三视图保持几何方向。−1°以下仅作连续数值延拓，不能替代现场大气测量。

当地日事件使用独立口径：太阳/月球采用圆盘上边缘，恒星采用点目标；标准 34′折射按海拔大气密度缩放，当地水平地平、相对地面眼高为 0。事件不随画面折射、用户气压温度、地景轮廓或图层开关改变。晨昏采用太阳中心几何高度 −6°、−12°、−18°。

查询覆盖当前地点的完整民用日，包括 23/25 小时的时区日。可能只有一次升起或落下，也可能周极、终日不升或没有某类晨昏；星座整体不提供升落事件。不可用或计算未完整的结果会说明原因，不补造事件。

## 农历与天空外观

农历来自固定生成器的离线民用日期表，覆盖公历 1901–2100，使用 UTC+8 日界。2057/2089/2097 保留未来预测不确定标记；2057 的来源表差异见 [农历说明](../assets/licenses/LUNAR-CALENDAR-NOTICE.md)。农历日期与月相时刻不是同一个概念。

日光、月光与人工亮度共同影响地表观察模式中的暗星显示、银河对比度和背景颜色。它是定性教学模型，未标定 SQM、Bortle、照度、天气或个人肉眼极限；示意及外部视图不施加同样的当地可见性衰减。

“模拟肉眼星空”使用星表中各恒星的视星等，并在当前极限星等附近平滑淡出。星座的每段连线随两端中较暗的恒星一起淡出，选中星座的高亮也遵守这个规则；切回“完整星图”可查看完整教学连线。暗夜、郊外、城市是人工天空亮度的示例预设，实际效果还受模拟中的日光、月光影响，不是特定地点的可见性预测。选中对象的方向标记仍可用于定位，不表示该星点肉眼可见。

三维地表视图的“地面透明”关闭程序地景遮挡，可展示地平线以下的天体方向，地平参考线仍可独立保留。它不改变天体高度、升落时刻或物理可见性；地平线以下内容只供几何教学。二维降级总览仍仅显示上半天，不提供透明地面的下半天显示。

地球、月面与银河均为固定来源图像。银河保留现代 J2000 近似方向，不能用于长期历史结构重建或测光。程序地景也不代表真实地形和地平遮挡。素材来源与许可见 [资产清单](../assets/assets-manifest.json)。

## 验证范围

开发检查包含固定 SOFA/USNO/JPL 等独立参考、解析性质、输入配对与显示一致性；这些检查覆盖明确样本，不认证整个 1900–2100 连续区间或扩展年代。本版定位是教学预览工具，精度与兼容性限制会随应用读数及发布说明保留。
