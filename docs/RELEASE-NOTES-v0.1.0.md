# v0.1.0 · 公开预览版

首个公开预览版，面向中文天文教学和个人探索。提供桌面离线单文件及静态 Web 包；不宣称跨设备稳定或全时空精度认证。

## 本版功能

- 地表、太空、天球、地平天球四视图，共用时间、地点和选择，独立保存相机。
- 8,921 颗 HYG 恒星、88 星座，中文/英文/HIP/HYG 搜索与对象高亮、定位。
- 日月与恒星当地日升落、三种晨昏、极昼极夜说明、月相放大镜、四月相搜索及农历。
- 银河、定性光污染、月光与日光对比；地表/二维几何和标准折射近似。
- 教学预设、本地场景库、JSON 导入导出、截图与 Web 场景链接。
- 单指/双指交互、移动布局、WebGL2 不可用时的真实二维回退、上下文恢复，以及保护科学量的运行画质调整。
- Web 离线缓存与等待更新机制；便携 HTML 内嵌运行资源和署名资料。

## 适用范围与限制

开发期间已完成固定科学参考、类型与功能检查，并在 Windows Chrome/Edge 验证主要流程和离线路径。最终 Firefox 检查有一次折射提交点击超时与黑色主画布观察；一次诊断未复现，根因未知，仍待兼容性确认。

macOS Safari、实体移动设备、真实 HTTPS 发行域上的系统 PWA 安装尚未验证，30 分钟连续测试暂缓。模拟触摸、短期性能与资源检查不构成这些平台或长期稳定性的证明。

扩展年代仅作探索；折射为经验近似，升落采用独立标准模型；光污染和静态图像不用于实时天气、测光或现场观测精度预测。模型口径见 [SCIENCE-MODEL.md](SCIENCE-MODEL.md)。
