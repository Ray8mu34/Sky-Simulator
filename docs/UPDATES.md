# 功能更新

## 2026-10-10：肉眼识星与透明地面

- 控制面板顶部“肉眼星空 · 光污染”提供“模拟肉眼星空”和“完整星图”切换。暗夜、郊外、城市预设及滑条沿用同一个天空外观模型，不改变时刻、地点或相机。
- 肉眼模拟中，星点按真实星表视星等淡出；每段星座连线随较暗端点淡出，包括选中高亮。标签和点击区域跟随可见性，选中对象可保留明确的定位方向标记。
- 地表“显示图层”中的“地面透明（看地平线下）”移除示意地面遮挡；地平参考线独立。二维兼容总览仍仅展示上半天，并说明此开关不可用。
- 光污染是定性教学模拟，未标定当地实测天空亮度或个人肉眼极限；透明地面是几何教学功能。详见[科学模型](SCIENCE-MODEL.md)。

验证包含类型检查、生产构建、天空外观/Canvas/球面弧定向回归，以及真实 Chrome 中的暗夜与城市对比、四视图切换、地平线下北极星、390 px 窄屏键盘操作和强制 Canvas 降级。截图由实际生产应用生成并人工检查。调整污染不重建球面弧、不上传弧缓冲或增加绘制次数；新增静态弧星等属性 384,500 字节、端点位置 16,224 字节。

这次没有重新执行完整 M6、30 分钟持续测试或实体手机矩阵。v0.1.0 发布附件与宣传截图继续代表原冻结版本；在线构建身份见[部署说明](DEPLOYMENT.md)。
