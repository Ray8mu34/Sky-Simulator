# 第六、第七批使用记录

## 课程

“课程 / 设备与地景 → 课程演示”提供示例课程、记录当前场景、步骤讲解与停留时长、前后步、自动播放、暂停及退出恢复。课程JSON包含完整场景，不执行JavaScript；最多100步、2 MB。每步暂停模拟时钟，待对应科学快照到达后计时；后台页面不累计停留时间，手动天空/设置操作暂停课程。退出恢复进入课程前的场景。课程标题和步骤讲解通过文本显示。

## 设备

相机支持焦距、传感器宽高与取景框旋转；目镜支持望远镜焦距、目镜焦距、表观视场，显示倍率及近似真视场。地表缩放下限扩展到0.05°，拖动灵敏度随视场缩放。适配视场切换到地表并调整视角；恢复广角关闭设备框。设备参数随场景保存。

相机视场为2atan(尺寸/2焦距)；目镜真视场采用表观视场/倍率，未使用视场光阑模型。不提供倒像/镜像光路或相机畸变模拟。小视场仍使用当前亮星目录，不能替代望远镜寻星深星表。二维回退保留参数但不显示设备视场。

## 地景

导入2:1等距柱状PNG/WebP，最大8 MB、8192×4096，内部采样缩至不超过2048×1024。天空区域应透明；左边缘北、1/4东、中心南、3/4西，中线地平；偏角可校准方位。三维地表启用且“地面透明”关闭时显示，替代程序丘陵遮挡。可开关、移除，并独立导入导出含图片的地景JSON包。

地景属于独立资源，不嵌入普通场景或课程；刷新后需要重新导入地景包。渲染是最高640像素宽的缓存重投影，适合轻量教学，不是高分辨率三维地形。地景不修改高度读数或升落事件。二维回退不显示全景。
