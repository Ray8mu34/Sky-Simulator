# 第六、第七批使用记录

## 课程

“课程 / 设备与地景 → 课程演示”提供示例课程、记录当前场景、步骤讲解与停留时长、前后步、自动播放、暂停及退出恢复。课程JSON包含完整场景，不执行JavaScript；最多100步、2 MB。每步暂停模拟时钟，待对应科学快照到达后计时；后台页面不累计停留时间，手动天空/设置操作暂停课程。退出恢复进入课程前的场景及地景。课程标题和步骤讲解通过文本显示。

从v0.2.0起，课程标题、已记录步骤及尚未录入的步骤文字/时长自动保存到此设备。刷新后恢复编辑内容，课程保持未开始。查看“课程草稿已保存在此设备”确认保存完成；存储被禁用、容量不足或另一页面已保存新内容时，保留当前编辑并提供重试/备份/重新读取。

“备份草稿”导出包括未录入文本的 `sky-course-draft.json`，即使没有步骤也能备份。载入示例或导入文件会在已有内容时先要求确认替换，可以先备份或保留当前内容。常规“导出课程”用于实际演示，至少需要一个步骤。

导入地景后勾选“课程携带地景”，或选择“采用当前地景”，导出得到 `sky-course-package.json`：`format: sky-course-package`、`version: 1`、`course`和一份`landscape`，总计最多14 MB。地景只存一次，不复制到每个步骤。继续接受旧版 `version:1` 课程JSON；格式或图像解码失败保留原课程。课程附带地景在开始演示时临时使用，退出恢复课前地景；不会自动覆盖独立保存的地景。

## 设备

相机支持焦距、传感器宽高与取景框旋转；目镜支持望远镜焦距、目镜焦距、表观视场，显示倍率及近似真视场。地表缩放下限扩展到0.05°，拖动灵敏度随视场缩放。适配视场切换到地表并调整视角；恢复广角关闭设备框。设备参数随场景保存。

相机视场为2atan(尺寸/2焦距)；目镜真视场采用表观视场/倍率，未使用视场光阑模型。不提供倒像/镜像光路或相机畸变模拟。小视场仍使用当前亮星目录，不能替代望远镜寻星深星表。二维回退保留参数但不显示设备视场。

## 地景

导入2:1等距柱状PNG/WebP，最大8 MB、8192×4096，内部采样缩至不超过2048×1024。天空区域应透明；左边缘北、1/4东、中心南、3/4西，中线地平；偏角可校准方位。三维地表启用且“地面透明”关闭时显示，替代程序丘陵遮挡。可开关、移除，并独立导入导出含图片的地景JSON包。

地景属于独立资源，不嵌入普通场景。v0.2.0会保存地景、方位校准及启用状态，刷新后恢复；课程可以显式附带一份地景。渲染是最高640像素宽的缓存重投影，适合轻量教学，不是高分辨率三维地形。地景不修改高度读数或升落事件。二维回退不显示全景。

资料使用浏览器IndexedDB保存，与应用离线资源缓存独立。它不是云端备份：清理站点数据、隐私模式、不同浏览器/域名以及便携文件位置变化都可能影响可用性。迁移或长期保存请导出课程草稿/课程包和地景包。多页面写入用事务内版本检查，冲突时旧页面不能覆盖较新的记录。
