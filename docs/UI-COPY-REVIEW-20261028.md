技能的strict审计退出码为1，报告4个“按钮无动作”。该规则仅识别按钮上的内联事件，不能识别本项目的 `addEventListener` / `listen` 绑定：

- `controls.ts` 的视角按钮由容器点击委托处理 `data-view`。
- `scene-controls.ts` 的取消、确认按钮分别注册点击监听，本轮浏览器已验证实际取消、覆盖和删除。
- `teaching-controls.ts` 的放大镜关闭按钮通过 `listen(..., 'click', () => showLoupe(false))` 处理。

上述4条经源码复核为误报，保留原始报告，不将strict审计称为通过，也不添加无意义的内联处理器来迎合检测。

浏览器验证使用Windows桌面Chrome与移动尺寸/触屏模拟；没有执行实体手机、Safari或读屏软件验收，不据此声称完整WCAG认证。现有颜色、字族和整体布局保持原规范，本轮新增的提示和确认行为已记录到交互契约。
