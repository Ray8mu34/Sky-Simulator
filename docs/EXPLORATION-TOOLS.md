# 第三至第五批：轨迹、日月食与天球图层

## 第三批：轨迹与高度曲线

选择日月、行星、恒星或Messier目标后，在“观测曲线 / 日月食 → 所选目标 · 本日高度”查看当地民用日的几何高度曲线。96个等时间间隔覆盖实际日界，包括夏令时23/25小时日；浅线为目标，虚线为地平，暗底为太阳低于−18°的区间。显示采样最高点和深夜且目标高于20°的采样计数，支持CSV导出。这不是连续中天求根或天气可观测性预测。

“显示图层 → 所选目标轨迹”绘制相对背景恒星的地心轨迹：太阳及行星前后90天、月球前后3.5天、其他点目标前后15天，121个节点。以当前UT整数日为窗口中心，标示起终点；不是当地天空中的周日路径。恒星/深空短时轨迹可能重叠成一点。

## 第四批：日月食

“观测曲线 / 日月食 → 日月食搜索与模拟”提供下次当地日食、全球日食和月食搜索。事件计算使用Astronomy Engine 2.1.19；接触按钮跳转并暂停，全球中心食提供食甚地点入口。

独立盘面画布随共享模拟时间更新，支持用原有播放/时间控制观察过程。日食采用站心日月角半径和方向；月食采用地影圆锥与球形地球半径扩大2%的教学近似，颜色仅作示意。盘面上北左东、同一角比例，并显示当地几何高度，地平线下可用于讲解但不表示当地能看见。

本批盘面模拟在教学面板中；主天空的大气亮度、月面着色、地球上食带和日冕尚未接入食象。事件求解器与盘面近似分别承担时间预报和几何演示，近接触阶段不应将画布边缘作为精确接触判据。

## 第五批：中国星官、边界与网格

- 传统中国星空来自Stellarium v24.4，共318条星官记录，312条具有可绘制连线；6条原始记录没有连线，未绘制。3段线因完整HYG4.1仍缺少端点而略去，详细编号保存在来源记录。
- 支持搜索“北斗”“紫微”“参宿”等已绘制星官，选择、四视图定位和场景导出。星官中心是连线端点平均方向，不是物理天体。
- 星官端点使用固定J2000目录方向；不随恒星自行推进，不用于长期历史星官重建。中国图层可与西方星座连线独立开关。
- IAU边界包含782段折线，覆盖88星座，坐标采用Stellarium提供的J2000边界数据。
- 赤道网格为J2000赤道网格，黄道网格为当日黄道网格，地平网格以当前地点为基准；每30°主网格，赤经刻度使用角度。
- 新图层默认关闭，显式开关随场景序列化，兼容缺少新增字段的旧schema-1场景。

图层适用于WebGL四视图和Canvas2D全天总览。参考图层是几何示意，不依肉眼极限判定是否显示。边界、曲线采用有限采样，视野/遮挡边缘可能出现短缺口。
