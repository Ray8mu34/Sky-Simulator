# v0.2.0 · 教学资料保存与版本更新

本版汇总第一至第七批功能，并改善课堂准备、资料恢复和版本识别。第八批的卫星、小天体、大星表和插件扩展仍处于规划阶段。

## 相比 v0.1.0

- 增加五大行星、110个Messier目标、观测高度曲线与CSV导出、多日轨迹、日月食搜索和盘面教学、中国星官、IAU边界及坐标网格。
- 增加课程步骤、相机/目镜视场、透明全景地景，以及肉眼识星和地面透明控制。
- 课程草稿及地景保存到当前设备；刷新后恢复资料，不自动开始课程播放。课程包可以附带一份地景，并继续接受旧课程JSON。
- 显示当前版本，提供检查更新入口。新版完整下载后提示保存场景、关闭所有本应用页面再重开；教学过程中不强制刷新。

## 下载与使用

- `Sky-Simulator-v0.2.0.html`：桌面便携版，运行资源和署名已内嵌，可直接离线打开。
- `Sky-Simulator-v0.2.0-web.zip`：完整静态Web包，用于HTTPS或本地静态服务器。不要单独打开其中的index.html。
- `SHA256SUMS.txt` 与 `release-manifest.json`：发行文件的字节校验与构建身份。

本地保存属于当前浏览器/站点，不是云端备份。浏览器清理站点数据、隐私模式、移动便携文件或换设备都可能影响资料恢复；迁移时导出课程和地景包。保存失败时界面保留编辑并提示导出。
